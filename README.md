## Descripción del proyecto

QA Test Center es una aplicación web desarrollada con HTML, CSS y JavaScript para gestionar casos de prueba, visualizar resultados y consultar evidencias de testing.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Cypress
- Node.js

## Funcionalidades

- Gestión de casos de prueba.
- Visualización de resultados.
- Consulta de evidencias.
- Generación de informes de pruebas automatizadas mediante Cypress.

## Objetivo

Aplicar los conocimientos de JavaScript mediante el desarrollo de una aplicación web funcional e interactiva.
